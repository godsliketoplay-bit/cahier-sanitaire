4. Commit/push les changements.
5. Attendre la publication GitHub Pages.
6. Fermer complètement la PWA puis ouvrir l'adresse GitHub Pages dans Chrome une fois.
7. Rouvrir la PWA.

Ne pas effacer les données du site si vous souhaitez conserver les données locales existantes.
